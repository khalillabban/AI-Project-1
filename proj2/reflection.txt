Difficulties Faced and How We Overcame Them:

One difficulty we faced was understanding how text can be used in a machine learning model. At first, it was not obvious how a sentence like "Win a FREE iPhone today!" could be processed mathematically. We overcame this by learning how TfidfVectorizer converts text into numerical features based on word importance. Once the messages were converted into TF-IDF vectors, the classifier was able to learn patterns that often appear in spam messages.
Another difficulty was dealing with the format of the dataset. The dataset did not behave like a perfectly clean two-column file at first, so we had to make sure the program only used the label and message columns. We solved this by selecting the first two columns, renaming them clearly, and dropping missing values. We also added exception handling so the program would not crash without explanation if the CSV file was missing or incorrectly formatted.
We also noticed that the dataset has many more ham messages than spam messages. This made us think about model bias, because a classifier could get a high accuracy by mostly predicting ham. We addressed this by using class_weight="balanced" in Logistic Regression so that spam examples had a stronger influence during training.
Another challenge was understanding the confusion matrix and classification report. Accuracy alone was easy to understand, but it did not fully show what types of mistakes the model was making. We overcame this by testing different messages and comparing the accuracy, confusion matrix, precision, recall, and f1-score so we could better understand the model’s performance.
We also had to make sure the interactive prediction loop was reliable for the demo. For example, the program needed to handle empty input and quit cleanly. We solved this by checking whether the user input was blank and by ending the loop when the user typed quit.

What We Learned:

Through this project, we learned how a simple AI system can be built using supervised learning. We learned that a classifier needs labeled examples, where each message has a correct output label such as spam or ham. The model then learns patterns from the training data and is tested on data it has not seen before.
We learned that text classification requires feature extraction because machine learning models cannot directly understand raw words. TF-IDF helped convert each message into numerical values that represent the importance of words in the dataset. This was one of the most important concepts in the project because it connected natural language text to machine learning.
We also learned how to train and evaluate a model using scikit-learn. Logistic Regression was useful because it could classify messages and also provide probability values for confidence scores. The evaluation metrics helped us understand that accuracy is useful, but it is not the only important measurement. The confusion matrix and classification report gave us a clearer picture of the model’s strengths and weaknesses.
Overall, this project helped us practice Python file handling, functions, object-oriented programming, error handling, working with datasets, basic data visualization, model training, and model evaluation. It also showed us that a useful spam detection AI system can be built with relatively little code when using libraries such as pandas, scikit-learn, and matplotlib.
