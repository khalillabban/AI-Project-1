Difficulties Faced and How We Overcame Them:
- One difficulty was understanding sentence embeddings and how semantic search differs from keyword search. We overcame this by testing different student questions and checking whether the assistant retrieved the closest answer from the knowledge base.
- Another difficulty was setting up the required Python libraries. We solved this by creating a requirements.txt file and using a virtual environment.

What We Learned:
We learned how to combine NLP, embeddings, semantic similarity, sentiment analysis, and basic Python software engineering to build a small AI-powered support assistant.
